# Student Performance Analysis System

## Project Overview
A data analysis project that evaluates student academic performance using Python and Tableau.

## Technologies Used
- Python
- Pandas
- Matplotlib
- SQLite
- Tableau
- Jupyter Notebook

## Features
- Calculate average marks and grades
- Identify class toppers
- Analyze pass and fail results
- Store and search student records
- Visualize student and subject performance
- Create an interactive Tableau dashboard

## Dashboard
See `dashboard.png` for a preview of the Tableau dashboard.

## How to Run
1. Install Python and the required libraries.
2. Open the Python script or Jupyter Notebook.
3. Run the code using your student dataset.
4. Open the Tableau workbook to explore the dashboard.
