# Student Performance Analysis System

## Project Overview
This project analyzes student academic performance using Python and Tableau.

## Technologies Used
- Python
- Pandas
- Matplotlib
- SQLite
- Tableau
- Jupyter Notebook

## Features
- Calculate average marks and grades
- Identify class toppers
- Analyze pass and fail results
- Add, search, update, and delete student records
- Visualize student performance using charts
- Create an interactive Tableau dashboard

## How to Run
1. Install Python and the required libraries.
2. Open the Python code in Jupyter Notebook or your editor.
3. Run the program using the sample dataset.
4. Open the Tableau workbook to explore the dashboard.

##INPUT REQUIREMENTS
- Student name
- Class
- Python marks
- SQL marks
- Maths marks

## OUTPUT REQUIREMENTS
- Student average marks
- Student grade
- Pass or fail result
- Class topper details
- Class average and pass percentage
- Tableau charts and dashboard

## CONCLUSION
The Student Performance Analysis System helps organize student records, analyze academic results, and present useful insights through visualizations and an interactive Tableau dashboard.
